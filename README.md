# 🌿 Green Corner — Go Green Project X TE3

**Strong Roots, Great Growth, Useful Blooms.**

Website proyek kolaborasi X TE3 Kelompok 3 tentang penghijauan lingkungan sekolah, informasi tanaman, dokumentasi kegiatan, data pertumbuhan, jadwal perawatan, dan fitur tanya jawab sederhana.

## Deploy ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini ke root repository. Pastikan `index.html` berada langsung di root, bukan di dalam folder lain.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. URL publik akan muncul di halaman Pages.

## File

- `index.html` — halaman website utama. Versi ini menyematkan gambar dan kode halaman secara langsung sehingga bisa dibuka tanpa mengatur path CSS/JS tambahan.
- `assets/green_corner_smooth.css` — file CSS pendamping dari versi pengembangan.
- `assets/green_corner_smooth.js` — file JavaScript pendamping dari versi pengembangan.
- `assets/green_corner_ai_fixed.js` — file JavaScript AI sederhana versi perbaikan.
- `assets/bunga-ratna.png` dan `assets/bunga-kenikir.png` — gambar tanaman pendamping.

Catatan: `index.html` adalah versi website mandiri; file CSS/JS di `assets` disertakan sebagai file pendamping dan tidak otomatis ditautkan ke HTML mandiri tersebut.
